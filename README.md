# aura IMAGE STUDIO — Personal Image Consulting

A refined, luxury editorial website created with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and typography powered by **Cormorant Garamond** & **Plus Jakarta Sans**.

## ✨ Features & Design Highlights

- **Editorial Luxury Aesthetics**: Inspired by high-fashion magazines and bespoke styling ateliers.
- **Color Palette**:
  - Porcelain / Ice-Blue background (`#F2F7FA`)
  - Deep Navy Slate text (`#122130`)
  - Signature Muted Steel/Slate Blue accent (`#5D8197`)
  - Warm Sand & Linen tones (`#DECEBF`)
- **Typography**:
  - Headlines & Display: **Cormorant Garamond** (high-contrast display serif).
  - Body & UI: **Plus Jakarta Sans** (clean, modern geometric sans-serif).
- **Interactive Sections**:
  - **Hero**: Personal Image Consulting tagline with curated portrait photography.
  - **01 / 04 — Beyond Clothing**: Brand philosophy statement with signature typography.
  - **02 / 04 — The Methodology**: 4-step framework (*Essence & Discovery*, *Colorimetry & Harmony*, *Wardrobe Architecture*, *The Lookbook Blueprint*).
  - **03 / 04 — Curated Services**: 3 bespoke packages with deliverables and inquiry actions.
  - **04 / 04 — The Experience**: 3-step practical roadmap and client testimonials.
  - **Interactive Consultation Modal**: Seamless booking form for prospective clients.
  - **Editorial Footer**: Complete studio contact information, social links, and navigation.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/inaazavalaa-blip/aura.git
   cd aura
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```
